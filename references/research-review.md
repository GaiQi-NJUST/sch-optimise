# 前置调研、选型与审核流程

## 0. 阶段门槛

grill-me 初步需求 → 约 5 个相似项目与参考图 → 带证据的多轮 grill-me 比较/选型/结构决策 → 工程简介/功能图/方案 → 第一次审核 → 尺寸与 BOM 定稿 → 原理图落实/检查 → PCB 布局与 3D → 第二次审核 → 布线铺铜 → 验收。

收到新项目时先执行此流程。已有工程可以读取、截图、分析和备份；未审核前不擅自重排 PCB、替换器件或开始布线。规则访谈中的“y”不是工程方案审批。用户否决或修改方案时更新版本及变更摘要；更换主控、连接器、供电结构或显著尺寸变化须重新提交受影响的方案。

## 1. 找到约 5 个真正相关的参考

- 优先立创开源硬件平台，按功能、接口数量、协议速度、供电方式、产品外形、主控方案与板层结构筛选。
- 优先有实际原理图/PCB图、BOM、尺寸说明和实物验证记录的项目；作者称“已验证”记录为作者声明，不当作当前设计的测试结果。
- 逐个打开并视觉查看原理图、PCB正反面、3D或实物。记录名称、作者、项目原始网址、访问日期、使用的图以及借鉴点。
- 按用户要求保存平台允许获取的原始参考图或实际浏览器截图，保留原始比例与文件名映射，不用生成图片冒充开源项目图片。无法获取的记为未取得，继续寻找可访问参考。
- 优先保存原理图全图与PCB全图；封装密集处再保存局部。保留来源标注，禁止未经查阅仅根据摘要写“已看过PCB布局”。
- 约 5 个是目标而非硬凑数量。数量不足或证据缺失时明确标记，不能虚构来源或以不相干项目代替。

建议工程内目录：review/references/01-project-name/，包含 source.md、实际取得的图片及相关说明；对外引用时展开为实际绝对路径。

## 2. 形成比较表并推导尺寸

比较字段：项目、来源、功能/接口、主控、供电、层数/板厚、板尺寸、尺寸依据、正反面安排、连接器类型、验证状态、可借鉴点、不适用点。

- 尺寸证据按源工程或机械图、作者明确尺寸、含可靠标尺的图片依次使用。
- 无标尺截图及透视实物图不能直接当毫米尺寸。按已知封装估计时标注估算、依据和误差，不能标成确定值。
- 本工程板尺寸由具体连接器外形/开口方向、端口间距、通孔位置、外壳内腔、板边净距、固定结构、布线和装配空间共同决定。
- 审核前提交建议尺寸和推导依据，不把参考板尺寸机械照搬。本项目定稿需能容纳实际选定封装，不能只缩板框。

## 3. 真实采购选型表

每行至少包含：功能块、位号或预分配位号、数量、器件类别、制造商、完整型号、关键参数、准确封装、商城料号、产品购买链接、数据手册链接、库存/价格查询日期、选择理由、审核状态。

- 核实链接指向准确器件产品页，型号后缀、封装、引脚数、安装方式必须与 EDA 元件一致。搜索结果页不算最终购买链接。
- 被动器件也要对应可采购规格：阻容值、容差、额定功率/电压、封装以及必要的介质等；相同料号可合并数量并列位号。
- 连接器核对卧式/立式、顶贴/沉板、板厚要求、固定脚及实际插接方向；晶振核对引脚定义、负载要求和外壳接地脚，不能只看封装尺寸。
- 库存和价格必须现场查询，写明时点；未获取写“未核实”，不能写成现货。无准确购买链接的仅作候选，不能作为已定稿器件放入正式 PCB。
- 替代型号独立列出兼容差异，不因外观相似视为可直接替换。参考 BOM 仍需独立核查。

## 4. 审核包

在当前工程目录生成以下材料，命名可本地化，但内容不可省略：

1. review/REFERENCE_COMPARISON.md：约 5 个项目的比较表、实际参考图、来源及尺寸证据。
2. review/SELECTION.csv 与 review/SELECTION.md：可编辑采购选型表及易读版本。
3. review/FUNCTION_DIAGRAM.md：功能框图的可编辑源描述，配实际可查看的渲染图（如工具支持）。分别标清供电方向、电压、主要信号、输入与输出；“功能图”不能以PCB布局截图替代。
4. review/PROJECT_BRIEF.md：本次工程简介，包括用途、目标功能、接口与协议、输入供电与负载目标、参考项目、选型摘要、建议尺寸/板层、布局思路、当前待决问题和审核项。
5. review/DESIGN_PLAN.md：先写实施方案，包含电路分块、器件与封装核对、尺寸依据、正反面布局、关键网络布线、铺铜/回流、验证与交付计划。

不要只生成文件不展示：向用户列出绝对文件链接，显示功能图或可读框图，摘要列出主控、连接器、供电、预计尺寸与未决项。取得该版本明确确认后才继续 PCB 工作。

## 5. 审核记录

review/REVIEW_STATUS.md 记录材料版本、确认的用户消息摘要、通过的选型/尺寸/功能、要求调整项。没有明确确认时状态保持“待审核”，不能自动批准。

第二次审核提交确定尺寸后的 PCB 正反面布局和 3D，检查产品外形、插接方向、元件实体和双面空间。方案通过仅允许进入布局，不自动授权跳过第二次审核。两次审核材料均为阶段材料，不称为最终成果；第二次通过后连续完成布线、铺铜与验收。

## 6. 调研验收清单

- [ ] 已找到约 5 个相关项目，数量与缺失证据如实记录。
- [ ] 真正查看了参考图；实际取得的原理图/PCB图已归档并对应来源。
- [ ] 板尺寸区分已核实、推导和估算，不按屏幕比例凭空认定。
- [ ] 正式器件完整型号、采购产品页、数据手册与封装一致。
- [ ] 已输出选型表、功能图、工程简介 Markdown 与设计方案。
- [ ] 用户审核的是具体工程材料版本，不是抽象工作流。
- [ ] 尺寸与选型确认后，才开始 PCB 绘制。
