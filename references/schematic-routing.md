# 原理图连线技巧与验收

以下为已确认用户偏好的操作细化，不是新的已批准 PCB 数值约束。

## 1. 先识别网络再简化画法

修改前记录元件位号、引脚号、网络与标签作用域。把同网近邻识别为可合并候选；元件之间已有串联器件时不得绕过。完成后比较归一化的引脚连接集合，而不是只比较自动生成的网络名。

## 2. 选择表达方式

1. 同区近邻且无障碍：直接短线连接，删除纯粹重复的标签，但保留足够标识。
2. 多个同网电容等并列器件：可使用短公共电源干线和地干线，支路间距整齐，在明确分支点连接。分区仍保持紧凑。
3. 主控附近上拉、下拉、去耦或晶振支路：围绕对应引脚组布置，避免长线横穿主控本体。原理图位置不等于已满足 PCB 的实际距离。
4. 少量跨区通信：沿预留通道清晰连接；多次交叉、绕图或影响框标题时改用名称一致的成组标签。
5. 远距离电源分配或跨页网络：使用正确作用域的电源符号/标签或层次引脚，不拉贯穿整张图的重复电源长线。

## 3. 折线、支路和连接点

- 引脚端点、导线端点、标签锚点对齐同一电气栅格，不能只视觉贴近。
- 水平/垂直走线为主；先给核心引脚留出文字净空，再转弯。尽量减少折点与折返，不把原理图强制画成 PCB 的 45 度走线。
- 有意分支优先使用清楚的 T 形连接；避免难辨认的四向十字连接。需要相连的分支放置并核实连接点，不连接的交叉不放连接点；仍有歧义则重排。
- 不将两根不同网络的线重合，不留零长度线、重复叠线、悬空短线或孤立标签。电源符号需要实际接到网络锚点。
- 旋转/镜像器件可以改善布局，但只改变显示姿态，不改变引脚编号和功能映射。

## 4. 成组信号

- USB 的 DP/DM 等关联信号在原理图中并行成组表达，顺序一致，名称明确。成对画法仅用于读图，不等于 PCB 差分阻抗或长度匹配已达标。
- 多位数据线、控制线可以按功能分组；只有编辑器支持并正确设置总线名称、入口与成员映射时才用总线。装饰性总线不能代替电气连接。
- 接口针脚顺序必须服从所选连接器定义，不为让连线顺眼交换针脚或擅自交换正负信号。

## 5. 标签与公共干线的使用限度

- 一个分区内同网短支路共用标识，但长干线分到多个难追踪区域时保留必要重复标识。
- 避免“每个引脚一个标签”导致标签堆叠，也避免“全部拉实体长线”造成蜘蛛网。
- 不直接短接分割地、隔离电源、滤波前后节点；需特殊连接的按电路设计使用相应器件和网络。
- 电源输入/输出类型和 PWR_FLAG 根据实际驱动关系设置，不能用它掩盖漏接电源。

## 6. 每次整理后的检查

- 电气：引脚连接集合一致；无意外新增/合并网络；标签作用域正确；ERC 新增项逐条解释并修复。
- 排版：文字/标签不重叠；折线清楚；支路连接明确；分区框随内容收紧；没有纸外小元件。
- 视觉：实际打开整页及高密度局部渲染，不以工具返回 success 代替验收。
- 总结：记录哪些标签被同网短线替代、哪些长线改成标签，以及前后网表检查结果。
